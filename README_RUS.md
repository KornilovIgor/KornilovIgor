## Избранные инженерные проекты

### Sanctuary

Python-приложение с Telegram-интерфейсом и интеграцией LLM.

Приложение работает в Docker Compose на отдельной VM. GitHub Actions выполняет автоматические проверки и сборку, после чего `main` разворачивается через self-hosted runner с проверкой состояния приложения и автоматическим rollback при ошибке.

*Репозиторий приватный.*

### Домашняя инфраструктура

Личная production-like инфраструктура на Proxmox VE с отдельными ролями VPN gateway и application server.

Использую её для практики архитектуры инфраструктуры, сетей, контролируемых изменений, deployment приложений и эксплуатационной надёжности.

*Инфраструктурные репозитории приватные.*

### TinyBasic → Python

Университетский командный проект — транслятор TinyBasic в Python. Сейчас возвращаюсь к нему как к практике модернизации legacy-кода.

[Репозиторий](https://github.com/KornilovIgor/legacy-translator-basic-to-python)
